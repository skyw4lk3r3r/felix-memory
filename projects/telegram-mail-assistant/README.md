# Telegram mail assistant

Пересылка писем из университетского Outlook в Telegram и ответы на них из Telegram. Работает на Windows через Claude Code, Chrome и Telegram Bot API.

## Состав

| Папка | Назначение |
|---|---|
| `mail-task/` | Задача по расписанию (каждые 15 минут): читает Outlook через Chrome, пересылает новые письма в учебного бота. Скрипты `tg-send.ps1` (отправка и оформление), `seen-add.ps1` (список обработанных), `mail-index-add.ps1` (номера писем) |
| `study-bot/` | Сессия учебного бота: принимает «ответ №N …», готовит черновик, после «да» отправляет ответ из Outlook |
| `personal-assistant/` | Сессия личного бота: задачи из Telegram с подтверждением рискованных действий |
| `examples/` | Примеры файлов данных без личной информации |

## Как это устроено

1. Задача `university-mail-to-telegram` открывает Outlook в Chrome, берёт письма за 24 часа и сверяет их со списком `seen.json` (по ID письма и по теме, времени и дню).
2. Каждое новое письмо получает номер (`mail-index.json`) и уходит в Telegram скриптом `tg-send.ps1`: одно оформленное сообщение, длинные тексты делятся, фото и документы идут отдельными файлами.
3. Владелец отвечает боту «ответ №N …». Сессия бота составляет черновик и показывает его. После «да» ответ отправляется из Outlook (кнопка «Ответить», один получатель, вложения добавляются через второй file-input).
4. Всё, что меняет почту, настройки или доступ, делается только после подтверждения владельца.

## Что не хранится в репозитории

Токены ботов (`.env`), список разрешённых (`access.json`), списки писем (`seen.json`, `mail-index.json`), черновики, логи и временные файлы. Примеры форматов лежат в `examples/`. Список исключений в `.gitignore`.

## Развёртывание

1. Установить Node.js, Claude Code (`npm install -g @anthropic-ai/claude-code`) и Bun.
2. Создать двух ботов в @BotFather. Токены сохранить через `/telegram:configure` в отдельных папках состояния (`TELEGRAM_STATE_DIR`).
3. Скопировать файлы из репозитория в рабочие папки (пути в `sync.ps1`, он работает в обратную сторону: из рабочих папок в репозиторий).
4. Создать задачу по расписанию с содержимым `mail-task/SKILL.md` и cron `*/15 * * * *`.
5. Плагин Telegram включить только в проектах ботов (`.claude/settings.json`), глобально выключить.

## Известные ограничения

- Работает, пока открыты приложение Claude, Chrome с входом в Outlook и окна сессий ботов.
- Один бот должен слушаться только одной сессией.
- Telegram позволяет до 4096 символов в сообщении, длинные письма делятся на части.

## Обновление репозитория

Запустить `sync.ps1`, затем `git add -A` и `git commit`.
