# Память Felix: как устроена папка

Здесь лежат заметки, которые помогают мне помнить контекст между сессиями.

## Файлы
- `/home/user/CLAUDE.md`: основные правила и профиль. Читается в начале каждой сессии.
- `/home/user/memory/log.md`: журнал важных решений, договорённостей и дедлайнов. Новые записи добавляются вниз, с датой.
- `/home/user/memory/open-questions.md`: вопросы, на которые Felix ещё не ответил.

## Правила
- Записывать только то, что Felix сам сказал или подтвердил.
- Не сохранять пароли, номера документов, адреса, данные банковских карт и коды доступа.
- Если информация устарела, исправлять запись и отмечать дату изменения, а не дописывать рядом противоречие.
- Перед тем как удалить запись, спросить Felix.
